Admin-Bereich

Bitte melde dich an, um Inhalte, Termine und Insights zu verwalten.

Admin

Inhalte bearbeiten

Wähle eine Seite und klicke direkt im Vorschaufenster auf einen Text, um ihn zu ändern — genau wie er auf der echten Website aussieht. Nicht vergessen: unten im Vorschaufenster auf „Speichern“ klicken.

Für Inhalte, die sich nicht einfach anklicken lassen: Themenlisten, die Preistabelle und Bild-Pfade als Rohdaten.

Termine

Alle gebuchten Termine der nächsten Wochen. Zum Absagen auf „Absagen“ klicken — der Termin wird dadurch sofort wieder frei buchbar.

Verfügbarkeit

Lege fest, an welchen Wochentagen und Uhrzeiten Termine buchbar sind. Format je Zeile: 09:00-12:00 — mehrere Zeitfenster pro Tag mit Komma trennen, z.B. 09:00-12:00, 14:00-17:00. Leer lassen = an diesem Tag keine Termine.
